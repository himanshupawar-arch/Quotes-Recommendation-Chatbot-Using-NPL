# Quotes Recommendation Chatbot (NLP)
**Developed by:** Himanshu Pawar  
**Domain:** Artificial Intelligence & Machine Learning

## 📌 Project Overview
This is an AI-powered recommendation engine that uses **Transformer-based Neural Networks** to match human intent with curated wisdom. Unlike standard keyword-search bots, this system employs **Semantic Search** to understand the context and emotion behind a user's input.

## 🚀 Key Features
* **Neural Encoding:** Uses `Sentence-BERT` to transform text into high-dimensional vectors.
* **Semantic Mapping:** Leverages **Cosine Similarity** to find the mathematical "closest" match between user feelings and data.
* **Stochastic Selection:** Implements **Top-K sampling** to ensure diverse, non-repetitive responses.
* **Human-Centric Logic:** Specifically tuned to recognize and respond to human emotional states.

## 🛠️ Technical Stack
* **Language:** Python
* **Models:** SBERT (all-MiniLM-L6-v2)
* **Libraries:** Sentence-Transformers, PyTorch, Pandas
